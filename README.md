# Лабораторная работа 2. Мультимодальные модели и адаптация домена

Тема ВКР: «Сравнительный анализ методов выравнивания распределений для адаптации домена в задачах компьютерного зрения».

В работе проверяется, помогают ли текстовое описание и простые числовые свойства изображения распознавать объекты при переходе от фотографий товаров **Product** к рисункам **Clipart**. В качестве сильной общей основы использован [SigLIP 2 Base Patch16 224](https://huggingface.co/google/siglip2-base-patch16-224), версия `75de2d55ec2d0b4efc50b3e9ad70dba96a7b2fa2`. Его кодировщики изображения и текста заморожены. Сравниваются восемь схем объединения трёх входов, а также MMD и CORAL, одномодальные контроли и распознавание zero-shot без обучения классификационной головы. Дополнительный набор Digits служит проверкой на ином, искусственно созданном сдвиге стиля.

**Основной результат.** На тестовой части Clipart zero-shot SigLIP 2 получил Macro-F1 **0,879**, визуальная обученная голова — **0,862**, а выбранная на Product validation схема объединения `concat_mmd` — **0,634**. Для этой задачи добавление зависимых от того же изображения текста и чисел не помогло. На Digits выбранная схема `mean_mmd` получила **0,832**, но визуальная модель с тем же MMD — **0,821**: основная прибавка связана с выравниванием, а не с объединением входов. Подробности и доверительные интервалы приведены в отчёте.

Главный документ — `Лабораторная_2_Мультимодальная_адаптация_домена.docx`; рядом находится его PDF-копия. Матрица 15 исследований и проверенные адреса публикаций находятся в `literature/`. Паспорт данных — `Паспорт_данных.md`, сопоставление с заданием — `Соответствие_заданию.md`.

## Состав проекта

- `configs/protocol.json` — зафиксированные параметры, разделение данных и правило выбора схемы.
- `data/` — строки с идентификаторами и разделами, компактные признаки, проверка целостности и происхождение данных.
- `src/extract_features.py` — извлечение векторов SigLIP 2 и **19 статистик одного изображения**.
- `src/zero_shot.py`, `src/train.py` — zero-shot ориентир и обучение 13 конфигураций на трёх seed для двух наборов.
- `src/analyze.py`, `src/paired_controls.py`, `src/ablation_retrain.py`, `src/summarize.py` — выбор по исходному домену, сравнения, абляции и сводки.
- `src/build_report.py` — сборка отчёта из сохранённых результатов.
- `results/` — вероятности, веса небольших обученных голов, истории обучения, метрики, таблицы и график.

## Повторный расчёт

Нужны Python 3.12 и изображения предыдущей лабораторной в соседнем каталоге `../lab1_officehome/data/images/` вместе с `../lab1_officehome/data/manifest.json`. Строки с автоматическими метками Apple Vision уже сохранены в `data/officehome_rows.json` и `data/officehome_vision_labels.jsonl`. Для анализа готовых результатов загрузка исходных изображений и SigLIP 2 не нужна. Для **полного пересчёта признаков** требуется официальный checkpoint модели; его веса не входят в проект.

Метки Apple Vision были получены на macOS отдельным запросом `VNClassifyImageRequest` из `src/apple_vision_labels.swift`. Скрипт записывает до восьми категорий и их оценки уверенности для каждого изображения. `src/prepare_vision_text.py` берёт первые шесть названий категорий, соединяет их в строку и связывает с объектом по `id`; оценки уверенности в текстовую строку не входят. Для получения **новых** меток на macOS выполните `swift src/apple_vision_labels.swift ../lab1_officehome/data/manifest.json ../lab1_officehome > data/officehome_vision_labels.jsonl`, затем `python src/prepare_vision_text.py`. Системная версия Vision может измениться, поэтому для точного повторения опубликованных результатов используйте сохранённый JSONL.

```bash
cd /Users/alina/Desktop/ВКР/lab2_multimodal
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -c 'from huggingface_hub import snapshot_download; snapshot_download(repo_id="google/siglip2-base-patch16-224", revision="75de2d55ec2d0b4efc50b3e9ad70dba96a7b2fa2", local_dir=".model_cache/siglip2")'
python src/extract_features.py --dataset officehome --batch 16
python src/extract_features.py --dataset digits --batch 16

python src/paired_controls.py

```

Повторное обучение перезапишет файлы в `results/` и потребует заметного времени. Для просмотра уже рассчитанных результатов достаточно открыть отчёт и CSV в `results/`. Истинные метки целевого домена используются при оценке после выбора схемы; для настройки модели они не передаются. Метки Clipart, Art и Real World, однако, уже рассматривались в прежнем варианте работы, поэтому эти выводы следует считать **исследовательскими**, а не независимым подтверждающим тестом.

Office-Home и Digits не содержат временных наблюдений. Их 19 числовых свойств — характеристики **одного** изображения, а не временной ряд. Поэтому часть задания о синхронизации с временным рядом и тесте на будущем периоде на этих данных не выполнена; это открыто отмечено в отчёте и `Соответствие_заданию.md`.
